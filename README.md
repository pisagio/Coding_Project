# 🏀 NBA Data Analysis

This project was developed for a university coding exam focused on **data analysis and object-oriented programming in Python**.  
It analyzes NBA player performance using **regression models, statistical indicators, and data visualization** to identify trends and efficiency metrics.

---

## 📂 Project Structure

- **index.html** — Interactive HTML report generated from the notebook (viewable in browser)  
- **nba_data_analysis.ipynb** — Full Jupyter Notebook with code, documentation, and outputs  
- **data/** — Folder containing CSV datasets used for the analysis  

---

## 🧠 Key Features

- Implemented **object-oriented programming** for player data modeling  
- Performed **data cleaning and preprocessing** using Pandas  
- Built **regression models** to study relationships between performance metrics  
- Created **interactive visualizations** with Matplotlib and Seaborn  
- Delivered a final **HTML dashboard** for visual exploration  

---

## 🛠️ Technologies Used

- **Python**  
- **Pandas**, **NumPy**  
- **Matplotlib**, **Seaborn**  
- **Jupyter Notebook**
